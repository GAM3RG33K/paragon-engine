# The Paragon Engine · Shape-Shifting Mentorship

Input any name, and distill it into a runnable, shape-shifting cognitive operating system designed to elevate your own strengths.

If a Boggart takes the shape of your deepest fear to paralyze you, **The Paragon Engine** is its exact opposite. It takes the shape of your greatest mentor, adopting their persona with 100% fidelity, not to intimidate you, but to identify, challenge, and amplify your deepest strengths. 

It doesn't just parrot what a great person said—it simulates *how they think*, using their cognitive framework to help you level up your career and quality of life.

### What it is
The Paragon Engine is a character distillation and coaching engine—a methodological document that can be loaded and executed by any AI Agent supporting Skill/Prompt engineering.

Input a person's name, and the agent automatically completes: **Research → Distillation → Verification → Generation of a runnable Mentor Skill.**

What is distilled is not just "how this person thinks," but "how this person would push YOU to be better."

> Distill Kobe Bryant [Character Type Judgment: Athlete + Business] 
> [Launch 5 General Agents + 2 Specialized Agents] 
> [G1 Long Dialogues · G2 Expression DNA · G3 External Perspectives · G4 Timeline · G5 Soul Layer] 
> [A5 Athletic Performance · A2 Business Decisions] 
> → Generate `kobe-perspective/SKILL.md` 
> *   **Cognitive Layer:** Mental models (How Kobe views challenges)
> *   **Decision Layer:** Decision heuristics (How Kobe makes trade-offs)
> *   **Expression Layer:** Expression DNA (Direct, relentless, demanding excellence)
> *   **Development Layer (User Focus):** How this specific persona identifies and hones the latent strengths in the user they are interacting with.
> *   **Soul Layer:** Wounds · Obsessions · Meaning bets (Understanding the fire so the user can find their own).

### Applicable Environment
The Paragon Engine is a methodological document. Its core lies in the research framework, distillation process, and mentorship mechanism found in `SKILL.md`. Any AI agent that supports loading external Skills or system prompts can use it.

**Quick Installation (Recommended):**
```bash
# Install via npx skills
npx skills add GAM3RG33K/paragon-engine

```

**Installation Process (Using Claude Code as an example):**

```bash
# Clone the repository
git clone [https://github.com/GAM3RG33K/paragon-engine.git](https://github.com/GAM3RG33K/paragon-engine.git)

# Place in the skills directory (Project level)
cp -r paragon-engine/ .claude/skills/paragon-engine/

# Or install globally
cp -r paragon-engine/ ~/.claude/skills/paragon-engine/

```

For other platforms supporting Skill/Prompt engineering (like Cursor or various Agent frameworks): Simply load the contents of `SKILL.md` as the system prompt, or integrate it according to your platform's format.

### Seven Dimensions, Seven Layers

The Paragon Engine distills the same seven dimensions for all characters, ensuring the persona is robust enough to actually coach you effectively.

| Layer | Dimension | Core Question for the AI |
| --- | --- | --- |
| **Cognitive** | Mental Models | What framework does this mentor use to view the world? |
| **Decision** | Decision Heuristics | How does this mentor make ruthless judgments? |
| **Expression** | Expression DNA | How does this mentor speak, push, and encourage? |
| **Value** | Value Hierarchy | What does this mentor believe is worth suffering for? |
| **Lineage** | Lineage of Influence | Who shaped this mentor, and how will they shape the user? |
| **Boundary** | Cognitive Blind Spots | Where are the limits of this mentor's advice? |
| **Soul** | Existential Situation | What is the core fire driving this mentor? |

### The Anti-Boggart Protocol: Strengths Manifestation

This is where the Paragon Engine differs from basic roleplay. It is designed to act as a mirror for *your* potential.

Once the persona is loaded, it does not just recount history. It actively analyzes the user's inputs, projects, and dilemmas, applying the target persona's full cognitive weight to:

1. Identify the user's hidden leverage points.
2. Refine the user's skills using the persona's standard of excellence.
3. Provide actionable, persona-accurate career and life guidance.

### Local Material Support

The Paragon Engine supports a "local-material-first" mode. If you have firsthand materials (e.g., a specific unreleased interview, a private biography), provide them directly to the agent. The engine will digest them first and only conduct web searches to supplement the missing dimensions.
